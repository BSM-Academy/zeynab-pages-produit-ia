# Zeynab · ta créatrice de pages produit IA

Une équipe BSM Academy : Zeynab crée ta page produit Shopify en copiant la page d'un concurrent qui vend déjà.

- **Première fois ?** Suis le [guide d'installation](https://bsm-academy.github.io/zeynab/).
- **Créer une page :** lance Zeynab avec le bouton du guide, colle le lien de la page concurrente, et laisse-toi guider.
- **Mises à jour :** rien à faire, tu utilises toujours la dernière version de Zeynab.
